About This Project

AICTE Problem Statement #18 — AI Grant and Funding Finder for Startups

🎯 Challenge

Funding opportunities are spread across multiple platforms with different formats, languages, and update frequencies. Extracting eligibility, deadlines, and requirements from unstructured content demands robust NLP. Personalising results based on startup stage, domain, and location adds complexity. Generating tailored proposals must balance accuracy and creativity, while respecting legal boundaries.

🤖 IBM Technology Used

IBM Granite (Mandatory)

IBM Granite 13B Instruct model via watsonx.ai for: grant matching, proposal generation, grant summarisation, and eligibility extraction.

IBM Cloud Lite (Mandatory)

IBM Cloud Lite free tier hosting for the Flask backend, IBM Watson NLU for advanced NLP, and secure API key management.

watsonx.ai Platform

Foundation model inference endpoint for low-latency prompting with IBM Granite 13B and future fine-tuning capability.

IBM Watson NLU

Entity extraction, keyword analysis, and sentiment detection from raw grant HTML content across multiple languages.

🏗️ Architecture

Frontend (HTML/CSS/JS)
  ↕ REST API
Flask Backend (Python)
  ├── Grant Aggregator (RSS + Web scraping + Static DB)
  ├── Matching Engine (TF-IDF + IBM Granite AI re-ranking)
  ├── Proposal Generator (IBM Granite LLM)
  └── IBM Granite Service (ibm-watsonx-ai SDK)
